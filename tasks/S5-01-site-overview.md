## Read contract (all DTO fields **new** unless the seam above names them)

`GET /api/sites/{site_code}/overview?date=YYYY-MM-DD` selects one UTC day. With no date or range, imported Sites default to the DB clock's current UTC day and return that day in `window.utc_date`; the UI writes it to the URL for reload. Accept existing `from`/`to` only when exactly one UTC day; reject partial, conflicting or non-UTC selection with typed 422. For legacy Sites, translate `date=` into the same midnight `from`/`to` pair and retain the existing file-backed DTO; with no selection retain its existing `LATEST_RELEASE` default. Return versioned `SiteWindowSummary` for imported Sites:
