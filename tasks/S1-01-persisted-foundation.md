## Foundation API and screen

8. External routes use the existing `/api` mount: `GET /api/sites/{site_id}/foundation?at=&knowledge_at=` resolves both instants on the server (default server now) and returns resolved instants, Site UUID/code, selected Foundation revision ID/version, valid and recorded periods, topology/assets/devices, controls, pending gateway/sources, binding-incomplete state and configuration gaps. Invalid time gives validation error; no effective revision gives explicit not-found/empty state. Never silently substitute current configuration. `GET /api/sites/{site_id}/foundation/versions` lists persisted effective periods and revision IDs for UI selection, with a way to distinguish superseded recorded bases. `knowledge_at` is API-only in S1.
9. A narrow `POST /api/sites/{site_id}/foundation/revisions` publishes a future-effective or backdated change to battery `reserve-state-of-charge` only; source and critical-load priority lists stay read-only. Validate typed value/unit, ownership and interval before a transactionally locked insert/split/supersession. Old content remains immutable; recorded-time correction preserves the previous knowledge basis. Return new revision ID/version and effective period. Expose the minimal publish control on Foundation, plus version list/period selector. Persist selected `at` in the URL query and show historical label/period; reload/share retains selection. A selected past period cannot be mistaken for current.
10. At composition, a tenant-scoped import registry/read router sends `GET /api/sites` and `GET /api/sites/{site_id}` for registered imported codes to Postgres identity/current Foundation summary, lists each once and suppresses its matching YAML row. Unregistered codes retain existing YAML index/detail behavior; Foundation versions/detail/publish for those codes return migration-required. A code collision outside the registered canonical path/digest is an error, not store precedence. The imported Site's Foundation read/publish path uses Postgres only. No file-backed writer mutates its YAML source. Existing file-backed Overview, Evidence and dispatch/Performance are legacy comparison surfaces: for imported codes, their product reads and legacy writes/Commit refuse with a specific transition state or render `awaiting evidence migration`, never stale values beside a changed Foundation. Unimported Sites retain their current legacy behavior, labelled where visible. Configured SLD may read selected Postgres topology but shows no operating status. Lab shares the YAML Site repository: from import, refuse new Lab Site creation and **new Draft setup, start, step, run-to-end and Commit for existing Drafts** against that code at the service/composition boundary until Lab uses the registered Foundation/gateway snapshot. Commit stays blocked even for a Stage produced before import. Stage envelopes arise during execution; `GET /runs/{run_id}/stage` remains read-only historical inspection, labelled with its frozen YAML basis, and cannot seal or release anything. Historical run reads remain available. S2-02, S3 and S5 own later Evidence, Performance and Overview cutovers.

## Configuration gaps and lineage

11. For `MINIGRID`, name missing/invalid site code, name, type/timezone; no effective revision; absent typed component/rating for generator, PV array, battery, PCS, fuel tank, AC bus or declared load; broken topology reference or no AC-bus path; missing battery reserve, source priority or critical-load priority; and missing registered gateway/source for a declared device. Import first uses the existing strict Site document parser; Postgres/domain completeness may then accept a well-formed Site missing battery reserve and report that gap. Structurally invalid identity, topology or priority ordering is rejected before insert. A Site with valid identity but a configuration gap cannot claim readiness. It cannot download an acquisition snapshot or claim health. Report pending bindings separately; these are configuration gaps, not observed source health. Reject references outside the Site.
