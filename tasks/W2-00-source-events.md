Acceptance tests:

1. Golden v3 vector and Receipt V2 bytes remain unchanged. v4 numeric/state/event and EV delta round-trip canonically; exact keys/nulls, UTC, value/unit, kind/outcome, event/session/connector scope and source-time validity hold. Reject v4-only kinds under v3 with ordinal `SCHEMA_UNSUPPORTED`; missing/null IDs with `CORRELATION_INVALID`; malformed delta with the three `EV_DELTA_*` codes; bound-connector mismatch with `EV_CONNECTOR_MISMATCH`; unknown kind, invalid outcome/unit/time, private field and incompatible mapping with §1's exact codes. Each valid-header refusal has a persisted ordinal. A binding only in another tenant is whole-batch `CONFIGURATION_UNREGISTERED` at `mapping` with no ordinal, because the principal cannot select that binding set.
2. Replay same message bytes and same event under a new message ID: duplicate with first accepted reference. Event equality uses SHA-256 of canonical `{source,timing:{source_time,interval_start,interval_end},payload}` computed from stored text; transport message, mapping and published time are excluded. Changed message SHA gives byte-stable `MESSAGE_CONFLICT`; changed event identity SHA gives `EVENT_ID_CONFLICT`; distinct EV START collision gives `SESSION_ID_CONFLICT`. Test message+event and event+session double collisions, concurrent race loser, unlisted unique violation propagation, distinct contradictory terminal events accepted, and all receipt counts/reference fields after reload. A valid-header v4 batch with a malformed payload must still complete with a per-ordinal rejection; malformed identity/scope header remains whole-batch `INVALID_ENVELOPE`.
3. Upgrade from `0019` to `0020` with preexisting v3 evidence and compare rows/reads. The delta CHECK keys on `measurement='INTERVAL_DELTA'`; `conversion_kind` remains the binding conversion. Downgrade refuses while v4 event/delta, new conflict or cold job exists, without deleting evidence; after removing only test-created blockers, downgrade restores old checks/nullability and v3 reads. Probe composite Site FKs, partial unique indexes and append-only trigger. Run statement-level rule-8 probes (`python tools/writer_guard_probes.py`) plus applicable architecture/workflow guards and registry checker.
