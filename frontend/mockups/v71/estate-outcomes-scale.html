Item 9 · Why this changes. Today's grid puts one column per site and one row per outcome group. At 4 sites it reads well; at 25 each column is about 40 px wide and the outcome names no longer fit; at 100 or more it cannot be read at all, and only the single lead outcome of each group is visible. This draft turns it round: sites are rows (rows can grow without limit, columns cannot), the four groups are columns (always four), and a summary for each group sits on top. Use the switch at the top right to compare 4 sites with an illustrative estate of 120.

Outcomes across the estate

How each site is doing on what matters

1 · A summary for each outcome group. Each tile counts sites by their state in that group, for example "2 need attention · 1 watch". These are counts of sites, never a sum of money, energy or hours: those stay on each site's own figures. Select a state to list only those sites. The tiles follow the site type, region, readings and search filters, so "Cold room" shows the cold rooms only.

Counts of sites. Values are never added across sites here; each site's figures are on its own board.

2 · Find and narrow. Search by site name; filter by site type, region and readings; group by site type or region; sort by need for attention (the default), name, type or readings. With 8 sites or fewer, only the type chips and the view switch show, so the demo estate stays as simple as today.

3 · One row per site. Each group cell keeps what today's grid shows (the state and the lead outcome) and adds how many of that site's outcomes in the group need attention. The site name and every cell open the site's outcome board for the same dates. The header stays in view while scrolling, and the site name stays in view when scrolling sideways. 25 sites load at a time; on a phone each site becomes a card.

3 · Every outcome. Each site type has its own outcomes, so this view has one table per type. Each group can be folded to its lead outcome or opened to every outcome (3 to 8 per group). Each square is one outcome and shows its state by shape as well as colour. Outcomes marked ◦ are illustrative extras, added to show groups of up to 8.
