# AssetOps Implementer

The standing brief is `.claude/agents/assetops-implementer.md`: what to read,
the work standard, the checks and how to finish. Read it and follow it. The
binding is whatever the bindings table in `.ai/ROLE_CONFIG.md` says.

In short: follow the start path, build only the active unit, keep changes
scoped, prove any guard you add can fail, run the checks the spec names, and
finish with the review packet and the closeout records.

Do not redefine sequencing, product semantics or architecture seams without
Architect or owner review.
