## 1. Outcome composition — highest priority

Trace how observations, findings, signals, warnings, financial contributions, opportunities, actions, and verification results compose from individual assets through Site outcomes into Portfolio outcomes.

Explain:

- How `moves`, `checks`, `CONTRIBUTIONS`, outcome nodes, objectives, categories, and strategies interact.
- How multiple findings affecting the same outcome are composed.
- How one finding affecting multiple outcomes is handled.
- How multiple sites contribute to a portfolio outcome.
- Which existing composition rules are genuinely reusable across verticals.
- How actual financial performance, estimates, opportunities, exposure, and verified benefits are differentiated.
- What prevents duplicate counting.
- Whether existing structures support cross-site comparisons, shared economic drivers, and portfolio-level prioritization.
- Which behaviors are implemented but not sufficiently exposed in the UI.

Use actual code paths, schemas, tests, and concrete examples.

## 2. Portfolio-level economic reasoning

Determine whether the current implementation can answer these questions, wholly or partially:

**COO:** Which sites contribute disproportionately to avoidable operating costs, what drives the differences, and where should engineering attention go?

**CEO:** Which sites or interventions offer the best opportunities for profitable growth, operational improvement, capital protection, or investment?

**CFO:** Which sites and economic drivers explain portfolio performance against plan, and what portion is controllable, recoverable, or verified?

Distinguish existing portfolio aggregation from cross-site diagnosis, comparison, and constrained resource allocation.

Identify where existing composition supports these questions and where functionality genuinely stops.

## 3. Three-vertical economic capability inventory

For mini-grid, cold-chain and EV, inventory the existing:

- Physical measurements and analytical mechanisms.
- Commercial records and integrations.
- Economic contribution calculations.
- Opportunities and scenarios.
- Action and verification pathways.
- Portfolio-level outputs.

Identify the exact missing data and behavior for commercially meaningful executive decisions.

Pay special attention to existing capabilities that are not apparent from the current Portfolio cards.

## 4. Simulation and demo-data generation — cost and architecture

Inspect the actual simulator, scenario generation, ingestion and replay implementation.

Determine:

- Current simulation models and configurable parameters.
- Supported site counts, simulation duration, resolutions, and execution modes.
- Computational and storage costs as site count and time horizon increase.
- Which models are shared across sites and verticals.
- Whether targeted scenario windows, historical replay, sparse/event-driven generation, or cached baseline datasets are supported.
- Which generated datasets can be reused across executive demonstrations.
- Whether changing an intervention requires regenerating the entire portfolio or only affected periods/sites.
- How simulated source observations reach the current ingestion pipeline.
- Whether emulated third-party system interfaces already exist.
