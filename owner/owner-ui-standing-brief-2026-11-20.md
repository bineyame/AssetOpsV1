# Owner: the UI/UX theme as a standing brief (2026-11-20)

The owner asked:

> what it the key ui/ux theme you have picked up from my questions

The coordinator answered: deliberate information architecture — every piece of content is on screen because someone chose where and how to expose it, not because it was available. Drawn from the owner's questions: the Portfolio "disorganized, devoid of progressive disclosure"; "intentional and scalable UI real estate"; "I click Decide and see a very elaborate text, links, grids"; "why is one thing a panel, one a page, one brought up"; how information is organized where data spans several scrolls; "exposing content deliberately using the right controls … simplicity achieved through deliberate design"; "not another document". In practice: fix the pattern behind each symptom with a rule that gets unseen pages right first time; first impressions as a state-of-the-art commercial product matter as much as correctness; honesty underneath (wrong numbers on a clean page are worse than clutter); identity deliberate and configurable. The coordinator offered to save it as a standing brief: a short memory note plus one rule line, not a document.

The owner replied, verbatim:

> yes, save it as a standing brief
