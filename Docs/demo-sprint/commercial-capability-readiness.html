Exact arithmetic convention (R-X.2). Products stay exact, or the request is refused with 422, as today. The display rounds once, to 4 significant decimals, outward for bounds. A ceiling count (payback) is an integer computed exactly.

D1 Mini-grid productive-use contribution

BuyerMini-grid operator
DecisionAdd this productive load in eligible hours, or not?
MoneyCollected revenue − supply cost − enablement
ClaimEXPECTED_VALUE, MINI_OPERATOR

Economic model

unit contribution = E × tariff × collection_fraction − E × marginal_cost − other_cost_per_window (E = proposed_kW × duration_h) study contribution = eligible_windows × unit contribution collection break-even c* = (marginal_cost + other_cost_per_window / E) / tariff payback windows = ceil(enablement_cost / unit contribution) only when unit contribution > 0

Supply cost accrues on unpaid energy, so c* is the fraction below which every delivered kWh loses money. A payback count is never converted to calendar time.
