2.3 Standing rule DS-R1: demo-shaped logic is fixed when touched

If a slice touches demo-shaped logic, it fixes it in that same slice. "Touches" means it edits that function, rule, config or copy. Sharing a file is not enough.
  • Exception: when another planned slice already owns the fix, the item stays as a labelled keep, and the label names the owning slice.
  • Build sheets: every build sheet lists the items it touches and how each is resolved.
  • Reviews: reviewers check this. A touched item that is neither fixed nor labelled is a Medium finding, and High if a client would see it.
  • Never tune: no value is tuned so that it fits the data.
