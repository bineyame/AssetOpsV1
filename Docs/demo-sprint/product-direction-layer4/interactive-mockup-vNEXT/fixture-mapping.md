# Fixture mapping · Layer 4 rev 4 mock-up

Every figure on the added and changed screens is read at render time from `MANIFEST` (`fixtures.js`, generated by `tools/gen_fixtures.py` from `../demo-site-scenario-manifest.yaml`; the private `oracle:` block is removed and the build refuses a bundle that contains it) or derived by the arithmetic below. No figure is typed into a template except where this file says so ("text constant"). Paths are relative to the manifest root; `T0/T1/T2` = `tenants[0]` (Lakeside), `tenants[1]` (Harvest), `tenants[2]` (Metro); `S(k)` = `sites[k]`.

Each evidence drawer also shows its manifest path under "For reviewers: demo data reference".

## 3a. Protect measures (rev 5)

Read from `tenants[*].portfolio.protect.measures` (`loop-protect.js`): `id` → plain name (`PNAME`), `unit`, `target`, `class`, `sites` (manifest site names mapped to the mock-up's sites), `portfolio` (Σ), `november_to_date` (EV, shown in a separate table; Σ = `portfolio` or the sum of the site values), `detail` and `basis` (tags rewritten as "plain name (TAG)"), `shared_factor` (marked "same factor as the cost-to-serve line"), `items` / `note` for values at stake (listed, never summed). ## 4. Outcomes by site, Opportunity, What changed, Scope & coverage

- **Composition table**: site plan, October, `period.variance`; "not explained yet" per site = Σ residual factors.
- **Waterfall**: plan → every attributed factor (bridge rows and the Ruiru residual) → October; it sums to `portfolio.variance` (checked: Lakeside −852, Harvest −770, Metro −3,184.32).
- **Opportunity**: `MTO-HULLER.customer`, `load`, `economics`, `forward_replay`; `MTO-WELDING.economics`, `break_even_tariff_usd_per_kwh`, `reason`; `kobo.daytime_headroom`; `MWEA-AGG`; idle crate-days = `capacity_crate_days_oct − actual.crate_days`; Ruiru today = `physical.buses × kwh_per_bus_night` = 1,960 (derivation), +6 and +10 from `RUI-ABSORB6/10.required_kwh`, limit `deliverable_kwh`. The load-window chart uses only `load.window` values; the daylight band is a fixed 06:00–18:00 visual cue, not data.
- **What changed**: frozen predictions restate option fields (`forward_replay.avoidable_fuel_l`, `economics.net_monthly`, `load.kwh_month`, `KIRI-REPAIR.recovery_share/range`, `economics.monthly`, `EMB-DEADLINE.economics.kwh_0000_0500` and `saving_monthly`, `max_kw`); states are text constants consistent with `as_of` 6 Nov. Verdicts are all "Not yet". Rights: `claim_state`, `claim_events`, `notice_deadline`, `remedy_scheduled`, `sla_clock.restore_due`, residual or operator-funded costs.
- **Scope & coverage**: leaf factors and their classes from §1; sources from `sources.*` with `provenance`; missing records are text constants restating `coverage_note`, `entitlement.evidence` (MISSING), and the absent fields listed in CHANGE-REGISTER §7.
- **Pilot request**: minimum asks are text constants from the main design §4; `opening_proposition` from the tenant.

## 6. Evidence drawer

Definition and formula are built from the node or option above. Sample source rows are shaped like the record layouts in `sources.*` (`record:` field lists) and filled with the period totals of the same node; customer-level rows are not reproduced. Clocks: service period 1–31 Oct, recognised in October books closed 6 Nov (`as_of`), settlement to 2 Nov for cash (disorder test LATE-SETTLE-1). Provenance label is the source's `provenance`, shown as "Source-emulated demo record" or "Simulated demo data"; modelled splits are labelled simulated.
