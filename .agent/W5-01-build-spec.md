## Shared selected read and guards

`GET /api/sites/{site_code}/cold/cooling` and `/cold/health` reuse `cold_site_api.opened`: authenticate and Site-scope before lookup; enforce strict paired half-open UTC `from,to` at most 31 days, optional `known_at`, disclosure, one read-only REPEATABLE READ connection, and committed watermark. `schema_version:"cold-depth-1"`; response fields `site_id`, `window:{from,to,known_at,committed_watermark}`, `selection:{state,assessment_revision_ids,accepted_evidence_ids,source_provenance}`, page payload and `links`. The state is exactly `cold_reads.STATES`: `CURRENT`, `PENDING_RECOMPUTE`, `STALE_SOURCE`, `HISTORICAL`, `UNKNOWN`, with merged cold precedence (pending before historical). Exact accepted IDs are deduplicated cited IDs from the selected W2-03 assessment, episode/Finding and W2-04 read, never a page or cursor subset. `evidence/public_provenance.py` classifies the *entire* selected set: empty/broken/foreign is `UNKNOWN`; incompatible classes/runs are `MIXED`. No gateway/run-mode inference and no private Lab truth.

Cooling payload: `recovery_state` (`LIMITED`, `CONTRADICTORY`, `UNKNOWN`), selected accepted compressor/probe points and IDs, `observed_restart_at`, `observed_return_to_policy_at`, nullable `duration_lower_seconds`/`duration_upper_seconds`, `comparison_state` (`CONTEXT_MISSING` for existing W2 producer), and context rows for ambient, continuous power, door, loading and defrost. The W2 selected start chain lacks ordered recovery proof (`cold_site_reads.COOLING_TEXT` and W2-F S2), so all existing W2 replay cases keep duration null and comparison missing even if separate compressor/probe observations exist. Never show mock 36/42 minutes or +17% as measured. Health payload has effective configured `asset_id`, `observation`, `condition_state` (`NEEDS_INVESTIGATION`, `UNKNOWN`, `NOT_CONFIGURED`), `limitation`, selected accepted IDs and link. A selected failed generator start permits `NEEDS_INVESTIGATION`, not failed-part diagnosis. Compressor condition is `UNKNOWN`; one accepted probe permits `Limited` sensing coverage, not room-wide condition. Null is distinct from zero and from an empty array. Malformed 200 responses render refusal, not a fabricated empty state.
