## Selected read, calculation and wire guard

New `GET /api/sites/{site_code}/ev/availability`, `/ev/energy`, `/ev/health` reuse `ev_assessment_api.ev_gate`: authentication before Site lookup; repeated/unknown query keys 422 `EV_PARAMETER_UNKNOWN`; paired UTC `from,to` (at most 31 days), optional `known_at`; existing refusal wrapper `{error:{code,message}}`, disclosure and single read-only REPEATABLE READ snapshot. Response `schema_version:"ev-depth-1"`, `site_id`, `window:{from,to,known_at,committed_watermark}`, `selection:{state,assessment_revision_id,session_revision_ids,accepted_evidence_ids,source_provenance}`, page payload and `links`. Use unchanged `analytics/ev_reads.STATES`: `CURRENT`, `PENDING_RECOMPUTE`, `STALE_SOURCE`, `HISTORICAL`, `UNKNOWN`; EV `currentness_state` puts `HISTORICAL` before pending, unlike cold. If selection absent all denominators/numerators are null (not zero). Pending, stale and historical never present a current positive. Exact accepted-ID set comes from the selected session/evidence rows and relevant status/import/meter intervals in the same snapshot, deduplicated before `evidence/public_provenance.py`; empty/broken/foreign is `UNKNOWN`, crossed classes/bases `MIXED`.

Availability calculation version `ev-availability/1`: resolve each selected enabled connector's effective Foundation service schedule over the requested half-open UTC window, clipping to both. If no unambiguous time-valid schedule, `scheduled_seconds=null` and all rates null. For each scheduled connector-second, accepted trustworthy `ev_connector_state` transitions from the bound connector determine `AVAILABLE` for `AVAILABLE` or `UNPLUGGED`, `UNAVAILABLE` for `FAULTED` or `DISABLED`, and `UNKNOWN` for `PLUGGED`, `AUTHORIZING`, `CHARGING`, gaps, conflicting/stale/unattested state, and intervals after last valid state without proven hold duration. A **charging** state alone does not prove that the connector was available for a new session. Each transition's effective end is the next valid transition or the declared state validity end, never indefinite carrying to `to`; a zero-length or conflict is Unknown. Adjacent intervals union before counting; `known_available_seconds + known_unavailable_seconds + unknown_seconds = scheduled_seconds`. `known_time_ratio = available/(available+unavailable)` only if known seconds >0; `full_lower=available/scheduled`, `full_upper=(available+unknown)/scheduled` only if scheduled >0. Fractions are decimals, UI percentages round once to one decimal; the exact rational counts remain in DTO. Connector-level and Site-level rows share the same classified spans, never sum overlapping pages. A status observation outside the selected assessment's accepted set cannot classify any second. This is a bounded observed-state proxy, explicitly labelled `Observed connector state`, not physical availability certification.

Energy reuses W2-06 `supported_kwh`, `energy_complete`, W2-07 `overview.energy.complete_kwh/partial_kwh/unknown_seconds`, the selected import intervals and `financials` consequence basis; it does not resummarize session pages. `metered_complete_kwh` excludes incomplete session meter gaps, `partial_kwh` is separate, `observed_peak_import_kw` is max of accepted `ev_site_import` samples in the window (labelled sample peak), and `configured_import_limit_kw` comes from the effective Foundation revision. There is no `limit_caused_interruption` true from a sub-limit peak; `power_constraint_state` remains `UNKNOWN` unless independent requested and allocated limit accepted observations support a typed comparison. Existing gross tariff amount is shown only through W2-07 eligible consequence revision with exact source and currency; it is never cash collected or lost sales. `health` returns connector assets from effective Foundation, selected observed fault events and condition `NEEDS_INVESTIGATION` or `UNKNOWN`; `stationary_battery` is `NOT_APPLICABLE` only from the selected explicit no-battery Foundation, else `UNKNOWN`/configured Unknown condition. No charger state is `HEALTHY`.

Exact existing refusals come from `ev_gate`: `UNAUTHENTICATED`, `SITE_SCOPE_FORBIDDEN`, `EV_PARAMETER_UNKNOWN`, `EV_TIME_INVALID`, `EV_WINDOW_INVALID`, `EV_WINDOW_TOO_LONG`, `SITE_NOT_FOUND`, `EV_SOURCE_DISCLOSURE_FORBIDDEN`, `EV_READ_UNAVAILABLE`. Cursorless depth routes introduce no basis-change 409. Session/Finding/evidence links use IDs from W2 selected rows and selected revision IDs, not mock `SES-011`, `F-130` or `CHG-002` strings; keep `from`, `to`, `known_at` from the read.
