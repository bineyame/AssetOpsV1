## Rules and exact outcomes

Expected points are the 13 five-minute instants 19:00 through 20:00 in `[19:00,20:05)`; coverage numerator is distinct qualifying probe timestamps, denominator 13 (general windows derive their own aligned count), capped at 1. Need `>=0.8`, with no inferred path across a >10-minute gap. Above upper or below lower policy needs two consecutive GOOD samples at least five minutes apart; return needs two consecutive values inside band by at least effective `cold-return-hysteresis`. Start bounds `[last in-band,first out-of-band]`, end bounds `[last out-of-band,first stable in-band]`; initially out of band means unknown earliest start. Open episode has `duration_bounds.high=null`. Low duration is max(0, last continuously observed out-of-band point - latest start) for closed and open episodes, stopping at the first gap over ten minutes; high is latest return - earliest start only when both known. `degree_minute_bounds` is the sum of adjacent observed rectangles over intervals <=10 minutes using min/max exceedance; no gap area. `peak_observed` is the maximum observed HIGH sample or minimum observed LOW sample, never an interpolated extremum. Exposure Finding requires 15-minute low duration, >=0.8 coverage and source gate; otherwise POSSIBLE/UNKNOWN. No spoilage, part-failure or continuous curve claim. Normal -> `NO_EXCURSION_OBSERVED`. Excursion -> first high at 19:15, open, duration low 45 min, high null. Backup-failed -> same exposure, door CONTEXT. Missing-probe -> 7/13, temperature UNKNOWN and no exposure Finding. Late-reading -> 12/13 at 20:05 and 13/13 at 20:10 with new basis/revision, old history retained.

Start chain groups by `(correlation_id,generator_asset_id,outage episode)` and accepted event IDs. Required steps: POWER_LOSS, START_REQUEST, START_RESULT, generator state, TRANSFER_RESULT if sensor bound, bus state, compressor state, probe response. Within 30-second attested source-clock ordering tolerance, request 19:05 -> success 19:07 -> transfer 19:08 for normal. Explicit failed result 19:05 after 19:00 request supports `OBSERVED_FAILURE` only with no conflicting GOOD success. Timeout from Foundation = 5 min; inferred failure from timeout additionally requires complete generator state coverage through timeout. Missing transfer is `UNKNOWN_STEP` for transfer only; bus state cannot replace it. Contradictory GOOD success and failure for same correlation -> `CONTRADICTORY`, never failure. Equal event-ID conflict is a rejected S2 ordinal, not an accepted contradictory outcome. Excluded clock skew/SUSPECT/unbound records never support claims. Claim levels are `OBSERVED|BOUNDED|POSSIBLE|UNKNOWN|CONTRADICTORY`.

Episode key is SHA-256 canonical JSON array `[tenant_id,site_id,kind,subject_asset_id,first_qualifying_event_or_crossing_evidence_id]` (UUIDs lowercase text), stored as `episode_key_sha256`. Stable anchor survives late evidence changing bounds. A newly supported different anchor after old invalidation creates a new episode and `split_from_episode_id`; old episode gets an immutable `NO_LONGER_SUPPORTED` revision and FindingRevision. Other transitions are `SUPPORT_CHANGED` when linked evidence changes and `BASIS_REFRESHED` when only effective configuration/source gate/known cutoff changes. Excursion and start response have separate Findings, can share public events, and later use one overlap group. Reuse `postgres_finding_store.py:_insert_finding,_insert_revision` with domain `cold_chain`; avoid dispatch-specific candidate-minute fields.

3. **Q3, identity:** store `analytic_id='cold-excursion'`, `model_version='1'` (and `cold-start-response`/`1`) in existing analytic tables. The display/model identifier `cold-excursion/1` is their joined form, not the stored analytic ID.
4. **Q4, duration:** for an open episode, `duration_low=max(0,last continuously observed out-of-band source_time - latest_start)`. A >10-minute gap stops that continuous run. The half-open window end is a selection boundary, not an observed reading. For the 19:15 to 20:00 canonical run the lower bound is **45 min**, not 50. `duration_high` and both end bounds remain null until a supported return. For a closed episode, lower duration uses the last continuously observed out-of-band point, and upper duration needs both known start and return bounds.
5. **Q5, earliest start:** null unless the preceding qualifying in-band point is no more than 10 minutes before the first out-of-band point. A preceding out-of-band or excluded point cannot supply it.
6. **Q6, levels:** coverage below `0.8` gives assessment/episode `UNKNOWN` and no exposure Finding; conflicting GOOD same-instant probe values give `CONTRADICTORY`. With adequate coverage, a confirmed excursion with lower duration at least 15 min and a permitting gate is `BOUNDED` with an exposure Finding; a shorter confirmed excursion or a closed gate is `POSSIBLE` without one. A lone out-of-band point is assessment state `UNKNOWN`, level `POSSIBLE`. Fully in-band is `NO_EXCURSION_OBSERVED`/`BOUNDED` with no excursion episode or Finding. Do not turn a closed gate into a positive Finding.
7. **Q7, start Finding:** only `OBSERVED_FAILURE` plus permitting gate opens a start-response Finding. An explicit GOOD failure without conflicting GOOD success qualifies; a timeout qualifies only with complete generator-state coverage through its effective deadline. `OBSERVED_SUCCESS`, `UNKNOWN` and `CONTRADICTORY` do not open one.
8. **Q8, transfer:** only a qualifying `TRANSFER_RESULT` before the first `POWER_RESTORED` in the same correlation counts as backup transfer. Bus state can be observed while `TRANSFER` remains `MISSING`; a post-restoration grid transfer cannot close the backup step.
9. **Q9, peak:** for HIGH, `peak_observed=max(qualifying observed temperatures)`; for LOW, `min(...)`. Preserve the direction with the episode result/read. No interpolation or mock value supplies the peak.
10. **Q10, calibration:** resolve calibration while selecting the effective Foundation/`cold-roles-1` binding and primary room probe via `probe_asset_id`; pass only that eligible probe to the pure `ColdEvidence` rule. The pure record has no calibration field. Missing, duplicate or overlapping effective calibration/role periods fail closed.
11. **Q11, contradiction:** link each mutually conflicting accepted GOOD record as `cold_episode_evidence.use='EXCLUDED', reason='CONTRADICTORY'` (and show it in read exclusions). An S2 `EVENT_ID_CONFLICT` ordinal is not accepted evidence and never becomes this analytic contradiction.
