# S4-05b owner walkthrough - where the readings came from

What you are checking: every Finding, its Evidence, its fuel cost (Financials) and the Site Overview now say where
the records behind them came from, using the stored source record, and a current cost appears only when that source
is established. The four labels are interim wording for your W1 copy checkpoint:

| Label you should see | Meaning |
| --- | --- |
| **Prepared example data** | The records were prepared for an example (P01, P02). |
| **Generated test data** | The records were generated by a recorded Lab test run. |
| **Sources do not agree** | Some records have a registered source and some do not. No current cost is shown. |
| **Source unverified** | The source of the records behind the result cannot be established. No current cost is shown. |

The label and its sentence sit in a shaded box near the top of each page. It must be readable without opening
anything, also on a phone-width window. The details (record IDs, registrations) are in the "Source record for this..."
section below it, which you can open if you want.

You need two PowerShell windows. Docker Desktop (the database) must be running.

## 1. Build the example data (about 8 minutes, once)


checks each through the real API. It must end with `prepare finished ... failed checks: {'owner': 0, 'old': 0,
'mixed': 0}`. If it says `STOPPED`, stop here and send the output to the coordinator.

Then print the exact page addresses:

```powershell

```

Keep this output open; it is grouped into `[owner]`, `[old]` and `[mixed]`, and under each day it says what you
should see ("expected: ...").

## 3. Owner case: the normal examples

Window 1:

```powershell
.venv\Scripts\python.exe tools\s405_provenance_walkthrough.py serve --case owner
```

Open the `[owner]` addresses from `links` in the browser (each is `http://localhost:5435/...`):

- **P01, 23 Oct 2026** - Overview, Finding, Evidence and Financials all show **Prepared example data**. Financials
  and the Overview show a current fuel cost range from 0.00 to about 15.82 USD.
- **P02, 24 Oct 2026** - **Prepared example data**, and no current cost (the generator readings arrived late; the
  page says why). The "history, audit only" fuel cost link opens an older cost that is kept for the record and
  labelled as not current.
- **Ordinary Lab run, 2 Oct 2026** - **Generated test data** on all four pages, and no current cost (this day has
  no power quantity to cost).
- Reload any page: the label stays. Make the browser window narrow (phone width): the label box is still readable
  without opening anything and the page does not scroll sideways.

Press Ctrl+C in window 1 to stop.
