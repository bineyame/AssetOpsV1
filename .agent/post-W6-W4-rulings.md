4. **Q4, decision refusal copy.** Match exact codes before HTTP status. `PERFORMANCE_CUTOVER_CLOSED`: `Decisions are closed while the Performance assessment is unavailable. Try again when it opens.` No Reload and no claim that a later cutoff will work; the backend gate is closed independently of the selected cutoff. `DECISION_BASIS_CHANGED`: `The evidence changed. Reload this page.` `INVALID_KNOWN_AT`: `Choose a valid evidence cutoff.` `INVALID_WINDOW`: `Choose a valid Site-local window.` `INVALID_CURSOR`: `This page of results expired. Return to the first page.` The actual codes are `DECISION_DUPLICATE_KEY` and `DECISION_CORRECTION_CONFLICT`; both say `This change conflicts with a recorded decision. Reload this page.` Other 422 codes, including `INVALID_LIMIT`, `DECISION_INPUT_INVALID` and `DECISION_ATTESTATION_INVALID`, say `This request cannot be used. Check your entries and try again.` Other 409 codes say `The decision could not be recorded. Reload this page.` 503 and unknown unavailable: `Decisions are unavailable right now. Try again.` Retain existing 401/403/404 access meanings. Show an action only if the UI offers that action; a closed gate never offers Reload. Pattern: GOV.UK validation and recovery copy.

## Guidance used

- [WCAG 2.2](https://www.w3.org/TR/wcag/): use of colour, contrast, reflow, keyboard access, focus and visible content.
- [GOV.UK validation pattern](https://design-system.service.gov.uk/patterns/validation/): explain what failed and how to recover while preserving context.
- [GOV.UK tabs guidance](https://design-system.service.gov.uk/components/tabs/): clear labels and small-screen navigation; it warns that multi-line tab rows need careful association checks, hence the R453 recapture.
- [NN/g mobile tables](https://www.nngroup.com/articles/mobile-tables/): make overflow obvious when dense data needs scrolling.
