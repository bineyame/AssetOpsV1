# W5-03b E4/E6 UI: ruling-vs-code points for the Architect

Builder, 2026-10-24, branch `task/W5-03b-ev-health-ui`. Each point is where a ruling or card text does not match the merged code or producer. The build proceeded with the named choice. Confirm or rule otherwise.

1. **Fault fixture (ruling 8, E4 captures).** Ruling 8 names `settled(chain, "fault")` as the three-row fixture: c2 fault connector, c1 other connector, Site meter. On the served read that case has one session (c2, `fault_evidence_id: null`), so both connectors are `UNKNOWN` and the table has no fault row. `settled(chain, "interrupted")` gives the ruled composition, with the connectors reversed: c1 `NEEDS_INVESTIGATION` (1 selected fault record, session `…0255`), then Site import meter, then c2 with no assessment. `ev-health-fault` is captured from `interrupted`. Related: `test_w503_ev_depth_postgres.py::test_energy_health_selected_snapshot` checks the fault condition only for connectors that have a faulted session. On `fault` there are none, so it never checks `NEEDS_INVESTIGATION`. That file belongs to E1b, not to this unit, so it is not changed here.
2. **App prop name (P-E6-3/4/5).** The card says `App.tsx` injects `evScenarios?: EvScenariosClient`. Merged `App.tsx` already has `evScenarios?: EvScenarioChoiceClient` for the lab run-setup choice, and reusing the name breaks typechecking. The App prop is `evScenarioList` (cold precedent `coldScenarioList`). `SiteEvFrame` and `EvSiteFrame` take `evScenarios` / `scenarios` as ruled.
3. **Card link label.** The mock connector cards link `View detail →` (`index.html:181`, `metric(...,'sessions')`). The E4 card and ruling 5 name `Sessions →`. Built as ruled. No register row covers the label change.
4. **Literal plurals.** `{n} selected fault records; cause not diagnosed` (ruling 5) renders `1 selected fault records` on the interrupted fixture. The E6 `Accepted evidence` → `{n} records` line has the same issue for n = 1. Built literally.
5. **Session reference cell.** The E4 card's `Session {session_id}` + `Open Sessions →` bullet does not name its column. It is placed in `Supported assessment`, the observation it supports, as its own source-reference line under the assessment words.
6. **Health subtitle.** The mock subtitle is `2 × 60 kW connectors · 80 kW site limit · no stationary battery`. The frame keeps the shared `SITE_SCREEN_DESCRIPTIONS.health`, as cold Health does. No ruling covers it.
