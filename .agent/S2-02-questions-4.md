# S2-02 questions 4 (phase 3b, frontend) — fail-closed defaults applied

Q21. **Diagnostic upload refusal is not visible locally.** The gateway's local diagnostics read (`gateway/assetops_gateway/service.py` `_DIAGNOSTIC_COLUMNS` :1706) carries `state` and `last_attempt_at` but not `last_error_code`; a refused/failed diagnostic upload goes back to `READY` (:1420). The Lab cannot tell "refused by the server" from "not sent yet". Default built: `diagnosticUploadText` (`frontend/src/shell/GatewayPublicationPanels.tsx`) says an attempted-but-unreceipted diagnostic "did not produce a receipt; it waits to be retried. The reason is not shown in this local read" — never "refused", never "received". Proposed backend fix (for the backend implementer): add `last_error_code` to the local diagnostic row; the UI would then name the refusal.

Q22. **Evidence Analysis for an imported (Postgres) Site.** `analytics_api.py` stays legacy-gated, so the capability-readiness table is not shown on ledger Evidence. Default built: the ledger Analysis view holds the deeper evidence detail only (clocks, sources, deliveries, coverage, analysis status, comparison, refused readings, reading lineage) and states that no analysis conclusion is drawn here. No capability or Performance claim is rendered.

Q23. **Gateway health placement.** Built on Site > Evidence for imported Sites (plain sentence on Overview, detail on Analysis), not on Site Overview. Default: keep it there; the S2-02 packet names no other surface. Legacy Sites do not call gateway-health.

Q24. **Registered Commit button.** Offered only when execution is COMPLETED, the read is AVAILABLE, the claim is not fully released, and some unshared batch is unreleased ("Commit and release", then "Release newly sealed batches"). The server remains the authority (409 refusals render through the existing `Refusal`). The older `commitBasisBlock` copy ("committing such runs is not available yet") is only reached when GET commit carries no `registered_release`; confirm it may stay as the fallback.
