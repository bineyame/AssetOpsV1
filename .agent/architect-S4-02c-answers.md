## Q1 — sequence and source time

**Rule:** An admission-allocated gateway sequence is transport/admission order, not proof of source-time order. For a registered same-source, same-epoch stream whose source-time/interval semantics and clock quality are attested and valid, S3 must place readings by source time. A later gateway sequence with an earlier source time is a late arrival, not `SEQUENCE_ORDER_INVERTED` by itself. Preserve duplicate, overlap, conflicting epoch, untrusted clock, and impossible-time refusals; where the source-time basis cannot be established, report a named series limit rather than silently sort and claim coherence. This does not bless arbitrary backdating. The Lab-delayed publication clock supplies a deterministic case: the withheld report has no sequence before release, so admission numbering naturally runs backward against source time.

**Owner and timing:** S3 cohort/assessment (`dispatch-3.x`) plus S2 gateway/publication-profile proof, in `I-late-reading-series-and-money-limit`, **before S5-01's money read and before a real-Site pilot**. Changing the reviewed cohort rule requires a new model version, reassessment/reconciliation of affected current windows and preservation of old `dispatch-3.1` revisions and exact links as history. The implementer must prove both on-time-sequenced late upload and admission-sequenced delayed admission through accepted public evidence. A real gateway without validated source-time/clock semantics stays limited.
