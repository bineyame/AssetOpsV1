# S3-01 phase 1 questions (fail-closed defaults shipped or planned)

For one Architect batch; none blocks phase 1. Each names the default the build uses.

1. **Contradictory same-role case through the ordinary gateway.** Nothing in the simulator, observation transform or gateway produces two different values for one signal at one source time inside one cohort: the gateway holds a same-`report_key` different-bytes report as `CONFLICTING_REPORT` (`gateway/assetops_gateway/service.py:623-638`), and `inject_fault` has only DISK_PRESSURE/CLOCK_OFFSET. Default: produce the contradictory case as a second, labelled fault-fixture Batch V2 (S2-02 step-8b precedent, `D-2026-10-09-s2-credential-uncertain-commit-and-evidence-demo`), authenticated and centrally accepted but explicitly *not* gateway-sealed, under its own labelled epoch (`s3-contradiction-fixture-epoch`). Alternative needing a ruling: a gateway-side labelled fixture op that admits a second reading for the same channel/time.
2. **Poor-quality case.** The V3 contract allows `SUSPECT`, but nothing produces it; the gateway emits only GOOD or UNAVAILABLE. Default: the "poor-quality" case is UNAVAILABLE readings plus reporting gaps (discharge-capability reporting-availability window, dropout), named as such in the manifest; no SUSPECT value is fabricated.
3. **Overlapping runs share one sequence epoch.** `sequence_epoch` is per gateway config, so two registered runs over one window share epoch, sequence counter and snapshot SHA; public V3/Batch V2 carry no run field (`service.py:647-685`, `ingestion_batch_v2.py:177`). Default: the overlap case is produced the S2 way (same epoch, same window, two runs) and declared *ambiguous by construction* (expected ceiling Indeterminate/Limited, ambiguity named); a separable-cohort case uses a reprovisioned gateway epoch (`reprovision_epoch`). Phase 2 must not separate the two same-epoch runs by sequence ranges or receipt order.
4. **Template provenance for the generator demo values.** The property `source` vocabulary is only TEMPLATE|SITE. Default: `source: TEMPLATE`, `source_version: 2` (the `kobo-mini-grid-60kw` template version that introduced them) plus a revision `change_note` labelling it simulated demo configuration under `D-2026-10-08-s2-registered-kobo-demo-configuration`. No `DEMO` source is invented.
