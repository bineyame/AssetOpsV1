## Risks / open

- 2× cadence freshness, immediate-revoke rotation, direct-TLS-only (no proxy) are defaults pending Q8–Q10.
- Credential file permissions enforced owner-only on POSIX only; on Windows the ACL is left to provisioning.
- A batch shared between runs is never released by `release_run` and blocks `fully_released` (reported as `shared_batch_ids`).
- Diagnostic 409/422 at the gateway is recorded and not retried; it does not block evidence upload.
- `issue` writes the secret after committing the verifier; a failed file write leaves no usable credential until `issue` is re-run.
- Checked-in test-only TLS key under `gateway/tests/fixtures/` (valid to 2126; `cryptography` not installed).
