## Causal pack and public transform

Register `ev-charger/1` in the closed dispatch used by `host/execution_adapter.py`, `host/lab_execution.py` and simulator kernel, beside `cold-thermal/1`; never use fallback to fuel/mini-grid on unknown identity. Add pure pack under `simulator/assetops_simulator/packs/ev_charger.py` using the neutral `packs/errors.py:PhysicallyUnacceptable`. Start `UNPLUGGED`, no session/fault, 0 kWh. Per UTC minute apply forcing sorted `(time,connector,kind)`, with PLUG before FAULT at equal time. Plug assigns the deterministic scoped session ID; authorization lasts one minute; accepted charging emits START. Denial emits no START. Active fault emits FAULT+ABORT; pre-START fault emits FAULT only. Explicit unplug after active charge and without fault emits END. Grid loss pauses power; it never fabricates ABORT. Clear requires forcing. Available shared kW is `max(0,80-base_load)`, allocated in 1 kW round-robin quanta by connector ID with persistent pointer, bounded by request, connector and charger ratings; exact decimal `energy_next=energy+allocated_kw/60`.
